# DBI 超宽带采集 — Python 方法论仿真

**项目定位**：学院示波器组 **40–80 GSa/s 超高速示波器研制**项目的采集前端子系统——
数字带宽交错（DBI）架构正是此类示波器在 ADC 器件带宽受限下把有效采样率/带宽提升一个量级的关键技术
（0–10 GHz 双子带交叠采集 → 数字重构）。本仓库是对其中**数字重构链路**的方法论验证
（参考：赵禹博士论文《基于带宽交织技术的超宽带数据采集方法研究》，UESTC；
架构与校准链路描述与 CV 经历条目一致）。**合成信号验证，不含原项目数据与 RTL。**

## 仿真的系统

```
宽带输入 → AAFB 子带切分（A: 0–0.6 / B: 0.5–1.0，交叠带 0.5–0.6；1.0 ↔ 10 GHz）
         → B 路模拟本振下变频（0.55）→ ADC
数字重构：CORDIC NCO 数字上变频（DUC）
         → 宽带相关延时估计 → FIFO + 分数延时 FIR（48 阶 Kaiser sinc）
         → 交叠带相位对准（实测逐频点校正；生产链路中由数字全通 APF 参数化实现）
         → 升余弦交叠加权 → 拼合输出
```

B 路损伤模型：RF 段全通群延迟失真（r=0.9，峰 19 采样 @交叠带）+ 传输延时
（整数 137 + 分数 0.37 采样）+ 0.3 dB 增益纹波 + 60 dB SNR 噪声。
测试信号：99 音非等间隔多音梳（避免相关估计的周期模糊）。

## 结果（results/summary.md，全部为本机实跑）

| 指标 | 未校准 | 校准后 |
|---|---|---|
| 交叠带拼合响应 | −7.1 dB 凹陷 | **−0.03…+0.02 dB（凹陷消除）** |
| 总体通带纹波 (0.05–0.95) | 7.17 dB | **0.06 dB** |
| 延时估计（真值 125.26 采样） | — | 127.83（残差=前端全通群延迟散布，由相位对准吸收） |

校准后 0.06 dB 已优于论文交叠带补偿结构的 0.33 dB 参考值——原因：本 demo 的相位
对准按实测逐频点施加（构造上精确），论文用参数化全通逼近（0.33 dB 为其拟合残差）；
两者实现同一校正、精度档次不同，如实区分。

## 每采样复杂度（对应硬件资源量级）

| 环节 | 运算 |
|---|---|
| CORDIC NCO（DUC） | 24 级微旋转 = 48 次移位加减，无乘法器 |
| 分数延时 FIR | 48 MAC |
| 相位对准 | 生产链路 = 二阶全通 APF（约 5 MAC/采样，参数由实测交叠带相位离线设计）；demo 按实测逐频点施加 |
| 拼合 | demo 在频域施加；硬件为时域 FIR 加权 |

## 调试中确认的三个实现要点（留档，面试可讲）

1. **CORDIC 增益常数是一次性的**（0.607253 = 1/∏√(1+2^(−2i))），不是逐次幂；
   **且收敛域仅 ±1.743 rad**——±180° 输入必须先做象限预折叠（修复前 NCO SFDR 仅
   12 dBc，修复后 153 dBc）。
2. **均匀多音梳的互相关有周期模糊**——延时估计必须用非等间隔 comb 或时间戳。
3. **单节全通无法拟合驼峰形相位误差**（全通相位单调递减）——生产链路的 APF
   参数需按实测交叠带相位设计；本 demo 用实测逐频点校正实现同一传输函数。
